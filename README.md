# ☢ 热爱核平

> “我们热爱和平，所以要让世界变得——平。”

一款浏览器里的即时制黑色幽默策略小游戏。六个**纯属虚构**的国家在六边形世界地图上互相投送“核平包裹”，没有时间限制，最后活下来的就是“和平”。

**本游戏是虚构的讽刺类作品，与任何现实国家、组织和事件无关。**

## 在线试玩

打开 GitHub Pages 地址即可游玩（电脑浏览器体验最佳，建议宽度 1100px 以上）。

## 玩法

- **选择国家**：六个国家各有特性，比如刀盾的护盾更强、青铜的人口恢复更快、赛博朋克的科技更快、鱼叉的潜艇更便宜。
- **国力分配**：拖动左侧的科技 / 核武 / 三防滑条，右侧会实时显示每秒的收益。
- **科技树**：投送站 → 当日达 → 分装包裹 → 第 4 级二选一（主攻「闪送」/ 主防「拦截网升级」）→ 东风，冲东风共 575 点。两条路线都能研发东风，造出东风后还能补另一条。鱼叉天生拥有海底仓（潜航器）。
- **选择目标**：按 Tab 打开目标列表；或者点击地图上的其他国家，在弹出的情报浮窗里点「🎯 开始打击」。目标会显示在地图上方，国境线变成红色。
- **三种武器**：
  - ☢ 核包裹：大范围毁灭，生产慢。
  - 💥 导弹：飞得快、威力中等，库存上限 10，一次最多发 5 枚。
  - 小摩托（无人机）：生产快、飞得慢、拦截弹很难打中，主要拆敌国的投送站、机场等设施，消耗对方防空；库存上限 20，一次发射不限。
- **开火**：点圆形按钮发射，每次的数量由左边的档位键决定（核包裹 ×1 / ×3 / ×5 / 全部，导弹 ×2 / ×5，小摩托 ×5 / ×10 / 全部，档位会记住）；圆环显示下一个的生产进度；没有装填间隔，只要有库存就能点，不够档位的数量就有几个发几个。地图上每个国家名字下方显示人口和核弹库存。点击地图上的敌国会弹出情报窗口，可以直接在窗口里发射（同时设为目标）。
- **防御**：
  - 🛡 护盾（手动）：短时间保护全部国土，挡下所有常规导弹，核包裹伤害大减。适合应对大量来袭。
  - 🎆 拦截（可自动）：拦截弹锁定接近本土的来袭目标并在空中击落，优先打核弹，其次导弹，最后才是小摩托。适合应对少量来袭。
  - ⚡ 能量：科技全部研发完后，科技那部分国力全额转成能量；午夜后基础能量回复翻倍。
  - ✈ 升空拦截（自动）：敌方小摩托飞进国土时，库存里的小摩托从机场起飞迎击（同时最多 2 架），起飞就消耗、不返航，追着目标打到底。
- **空战**：任意两个不同国家的小摩托在空中相遇（不到 1 格）会互相攻击。
  - 🏗 重建（自动）：自动修复废墟城市和宕机设施。
- **国家大招**（Q）：每个国家一个，开局 90 秒后可用，比如卷王「加班投送」、青铜「燃烧吧小宇宙」、赛博朋克「断网攻击」。
- **午夜狂欢**：第 9 分钟起进入决战，核弹威力 ×1.25，之后每 2 分钟再 +10%（最多 ×2.5），越拖越难苟，弱势加成取消。
- **AI 难度**：开始界面可选简单 / 普通 / 癫狂。第一局默认开启新手提示；被 AI 盯上时，会提示它为什么打你。
- **手机**：竖屏时操作区在底部，左上角 📊 打开国情面板；单指拖动地图、双指缩放、点击敌国选目标。

## 生存模式（👽 三体人降临）

开始界面勾选「生存模式」，高阶文明**三体人**加入对局（只由 AI 控制，玩家不能选）：

- **高阶文明**：开局已研发投送站、当日达、分装包裹，产出 ×1.8、人口 ×1.3、护盾冷却 -30%；平时（恒纪元）受到的伤害 ×0.6。
- **智子封锁**：三体人活着时，其他所有国家科技速度 ×0.8。
- **降维打击**（大招，开局 4 分钟后可用，冷却 180 秒）：预警 10 秒，地图上画出两圈范围；随后 25 秒内二维化从中心展开。核心 5 格内人口清零、城市和设施全毁且 60 秒内不能重建；5～10 格按距离造成 80%～15% 人口损失（护盾减半），常常波及邻国。三体人开局就盯着真人玩家。
- **乱纪元**（弱点）：开局 5 分钟后，每 125 秒有 25 秒停产、护盾和拦截失效、受到伤害 ×1.5，提前 10 秒预警。这时各国 AI 也会集中火力围攻它——平时攒核弹，乱纪元一起发射。
- 纯 AI 测试中三体人胜率约 40%。

## 联机（测试版）

- 开始界面点 **🌐 创建房间**，把房间码或「复制邀请链接」发给朋友；朋友打开链接，或输入房间码点「加入」。
- 每人选一个国家（可以和别人重复，重复的国家会换颜色），房主设置 AI 数量、难度和速度后开始。最多 8 个国家（真人 + AI）。
- 房主的浏览器运行整个世界，其他人通过浏览器直连（WebRTC，借助 PeerJS 的公共服务器牵线），不需要自己的服务器。
- 联机时不能暂停或加速。有人掉线，由 AI 接管他的国家；房主退出，这局结束。
- 一局结束后点 **回到房间，再来一局**：连接保持，所有人回到房间后可以换国家、改名，新朋友也能加入，房主再点开始即可。
- 少数网络环境（部分公司网、移动网络）可能无法直连。

## 快捷键

| 按键 | 作用 |

| 空格 | 暂停 / 继续 |
| Tab | 选择目标 |
| F / C / D | 发射核包裹 / 导弹 / 小摩托（数量按档位；Shift+键 全部发射） |

## 本地运行

纯 HTML + CSS + JavaScript，没有任何依赖。在本目录启动一个静态服务器即可：

```bash
python -m http.server 8765
```

然后浏览器打开 `http://localhost:8765`。Windows 下也可以直接双击 `start.bat`。

## 技术说明

- Canvas 2D 渲染，发光效果用叠加混合实现；音效和背景音乐用 WebAudio 实时合成，没有任何音频文件。
- 所有数值集中在 `js/config.js`，方便调整平衡。
- 代码按职责分文件（普通脚本，按 `index.html` 里的顺序加载，不需要打包）：
  - `js/sim/`：模拟。`core` 开局与工具，`step` 每步推进与生产，`strike` 核包裹/导弹/小摩托与命中，`defense` 空战/拦截/护盾/大招/重建，`boss` 三体人（智子、乱纪元、降维打击），`end` 胜负判定
  - `js/render/`：渲染。`base` 地图与城市，`units` 飞行物，`labels` 国名与标牌
  - `js/ui/`：界面。`base` 面板与通用，`strike` 发射按钮/选目标/地图浮窗，`tips` 提示卡，`end` 结算
  - `ai.js` AI，`fx.js` 特效，`audio.js` 音效，`net.js` 联机，`main.js` 主循环与输入
