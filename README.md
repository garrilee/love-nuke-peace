# ☢ 热爱核平

> “我们热爱和平，所以要让世界变得——平。”

一款浏览器里的即时制黑色幽默策略小游戏。六个**纯属虚构**的国家在六边形世界地图上互相投送“核平包裹”，没有时间限制，最后活下来的就是“和平”。

**本游戏是虚构的讽刺类作品，与任何现实国家、组织和事件无关。**

## 在线试玩

打开 GitHub Pages 地址即可游玩（电脑浏览器体验最佳，建议宽度 1100px 以上）。

## 玩法

- **选择国家**：六个国家各有特性，比如刀盾的护盾更强、青铜的人口恢复更快、赛博朋克不怕辐射、鱼叉的潜艇更便宜。
- **国力分配**：拖动左侧的科技 / 核武 / 三防滑条，右侧会实时显示每秒的收益。
- **科技树**：投送站 → 当日达 → 分装包裹 → 第 4 级二选一（主攻「闪送」/ 主防「拦截网升级」）→ 东风（冲东风共 575 点）→ 路线专属的终极科技（主攻「分导东风」：东风落地时再分出 2 枚弹头；主防「全域护盾」：护盾时间 +50%）。造出东风后还能补另一条路线。鱼叉天生拥有海底仓（潜航器）。
- **全球事件**（不弹窗、不用读字）：每隔一分多钟来一次，空投和天气轮流出现。**空投**：地图上落下一个带光柱的补给箱，箱子上的图标就是奖励（☢ 3 个核包裹 / ⚡ 能量加满 / 🔬 70 科研点），点一下就领走，手慢会被 AI 抢走。**天气**：对所有国家同时生效的短暂状态，顶栏显示图标和倒计时——🌞 太阳风暴（拦截失效）、🌪 沙尘暴（小摩托停飞）、🏭 军备竞赛（产出 ×1.5）、🕊 全球停火（谁都不能发射）。
- **难度**：「癫狂」难度下 AI 产出 ×1.2、更好战，并且和玩家一样有逐帧的自动拦截。
- **选择目标**：按 Tab 打开目标列表；或者点击地图上的其他国家，在弹出的情报浮窗里点「🎯 开始打击」。目标会显示在地图上方，国境线变成红色。
- **三种武器**：
  - ☢ 核包裹：大范围毁灭，生产慢。
  - 💥 导弹：飞得快、威力中等，库存上限 10，一次最多发 5 枚。
  - 小摩托（无人机）：生产快、飞得慢、拦截弹很难打中，主要拆敌国的投送站、机场等设施，消耗对方防空；库存上限 20，一次发射不限。
- **开火**：点圆形按钮发射，每次的数量由左边的档位键决定（核包裹 ×1 / ×3 / ×5 / 全部，导弹 ×2 / ×5，小摩托 ×5 / ×10 / 全部，档位会记住）；圆环显示下一个的生产进度；没有装填间隔，只要有库存就能点，不够档位的数量就有几个发几个。地图上每个国家名字下方显示人口和核弹库存。点击地图上的敌国会弹出情报窗口，可以直接在窗口里发射（同时设为目标）。
- **防御**：
  - 🛡 护盾（手动）：短时间保护全部国土，挡下所有常规导弹，核包裹伤害大减。适合应对大量来袭。
  - 🎆 拦截（可自动）：拦截弹锁定接近本土的来袭目标并在空中击落，优先打核弹，其次导弹，最后才是小摩托。适合应对少量来袭。
  - ⚡ 能量：科技全部研发完后，科技那部分国力全额转成能量；午夜后基础能量回复翻倍。
  - 🎯 拦截弹药：拦截有自己独立的能量池（上限 60，一次消耗 18）；⚡ 护盾能量只给护盾用，不会被别的东西占用。
  - 🏗 重建：废墟城市和宕机设施全自动重建，不消耗能量和预算；同一时间修一座城市和一个设施，每处 14 秒，科技越高越快（全部研发完 9 秒）。
  - ✈ 升空拦截（自动）：敌方小摩托飞进国土时，库存里的小摩托从机场起飞迎击（同时最多 2 架），起飞就消耗、不返航，追着目标打到底。
- **空战**：任意两个不同国家的小摩托在空中相遇（不到 1 格）会互相攻击。
- **国家大招**（Q）：每个国家一个，开局 90 秒后可用，比如卷王「加班投送」、青铜「燃烧吧小宇宙」、赛博朋克「断网攻击」。
- **午夜狂欢**：第 9 分钟起进入决战，核弹威力 ×1.25，之后每 2 分钟再 +10%（最多 ×2.5），越拖越难苟，弱势加成取消。
- **AI 难度**：开始界面可选简单 / 普通 / 癫狂。第一局默认开启新手提示；被 AI 盯上时，会提示它为什么打你。
- **手机**：竖屏时操作区在底部，左上角 📊 打开国情面板；单指拖动地图、双指缩放、点击敌国选目标。

## 两种模式

开始界面有两个入口：

- **🗺 闯关**：十关，一关比一关难，每关开始前自己选国家。进度（通过了哪些关、每关几颗星）保存在浏览器本地，下次打开接着打；保存的是打到第几关，不是一局打到一半的战况。
- **☢ 生存模式**：自由对局，打到只剩你自己。随机分配一个国家；可以选 AI 数量和难度、是否加入三体人、是否快速局。联机也在这里（联机时各自选国家）。

## 国家扩张（单人生存模式）

单人的生存模式里，地图更大（46×27，平时 40×24），开局各国合计只占六成陆地，其余是空地：

- **自动扩张**：每个国家约每 6 秒占一块相邻的空地，离首都近的优先；人口越多扩得越快，被打残了就慢下来。辐射重的地块要等辐射散掉才能占。
- **占地的收益**：每新占 9 块地，轮流获得一座新城市（开始时人很少，慢慢长到普通城市的八成半）或一个新投送站。每个国家最多 9 座城市、8 个投送站。
- **瓜分灭亡国家**：被核平的国家留下的土地算空地，相邻的国家可以占。占到它的城市废墟就接管这座城市（自动重建，规模打六折），占到设施就接管设施。活着的国家的土地不能占。
- 联机和闯关暂时不开扩张。
- 纯 AI 测试（各 200 局）：4 国混战的对局中位数 13.6 → 15.3 分钟；「第一个击杀者最终获胜」的比例 47% → 40%，没有出现滚雪球加剧。有三体人时对局更长（中位数约 17 分钟），三体人胜率约 18%。

## 闯关

| 关 | 名字 | 敌人 | 队友 | 特殊规则 |
|---|---|---|---|---|
| 1 | 新兵训练 | 2 个很弱的对手 | 无 | 分步教学；敌人的核弹对你伤害打四折 |
| 2 | 初出茅庐 | 3 个简单难度的对手 | 无 | 无 |
| 3 | 虫群来袭 | 虫族 + 1 个对手 | 无 | 无 |
| 4 | 断粮 | 3 个对手 | 无 | 所有国家产出 ×0.6，午夜提前 |
| 5 | 铁幕 | 堡垒国 + 1 个对手 | 无 | 无 |
| 6 | 永夜 | 3 个对手 | 无 | 开局就是午夜狂欢 |
| 7 | 虫与墙 | 虫族 + 堡垒国 + 1 个对手（结盟） | 2 个 | 无 |
| 8 | 五国乱战 | 5 个癫狂难度的对手 | 1 个 | 无 |
| 9 | 降临 | 三体人 + 虫族（结盟） | 2 个 | 无 |
| 10 | 最后的堡垒 | 三体人 + 堡垒国（结盟，癫狂难度） | 2 个 | 无 |

- **队友**：不会打你，你也不能把队友设为目标；爆炸波及这类误伤照常生效。敌人全灭就过关，队友活不活都行；**你倒下就算失败**，哪怕队友还活着。
- **评星**：过关时剩下的人口占自己最高人口的比例，六成以上三星，三成以上两星，其余一星。
- **虫族**（只由 AI 控制）：不造核弹和导弹，小摩托孵化速度 ×10、库存上限 100，撞到城市的伤害 ×12，攒够 40 只就全部扑上来。没有护盾；护盾能把飞进国土的整群烧掉，沙尘暴时它飞不起来。
- **堡垒国**（只由 AI 控制）：护盾常驻（减伤 85%，导弹和小摩托完全挡下）。开局 80 秒后第一次「换班」，之后每 75 秒一次，换班时护盾失效 20 秒，提前 8 秒预警。
- 关卡是一张配置表（`js/config.js` 的 `LEVELS`）：敌人、队友、是否结盟、特殊规则。特殊敌人和特殊规则是独立的模块，以后可以随机组合。
- `tools/balance.html` 可以按关卡跑 AI 代打的通关率。

## 三体人（👽 三体人降临）

生存模式里勾选「三体人降临」（闯关第 9、10 关也会出现），高阶文明**三体人**加入对局（只由 AI 控制，玩家不能选）：

- **高阶文明**：开局已研发投送站、当日达、分装包裹，产出 ×1.8、人口 ×1.3、护盾冷却 -30%；平时（恒纪元）受到的伤害 ×0.5。
- **智子封锁**：三体人活着时，其他所有国家科技速度 ×0.8。
- **降维打击**（大招，开局 4 分钟后可用，冷却 120 秒）：预警 10 秒，地图上画出两圈范围；随后 25 秒内二维化从中心展开。核心 5 格内人口清零、城市和设施全毁且 60 秒内不能重建；5～10 格按距离造成 80%～15% 人口损失（护盾减半），常常波及邻国。
- **降维打击的落点会避开国家中心**：选一个预计让目标损失四到六成人口、且打完后明显高于灭国线的位置（每次方位随机），重创但不灭国。纯 AI 测试里，被打的国家 45 秒内灭国的比例从七成降到一成以下。
- **乱纪元**（弱点）：开局 5 分钟后，每 150 秒有 12 秒停产、护盾和拦截失效、受到伤害 ×1.25，提前 10 秒预警。这时各国 AI 也会集中火力围攻它——平时攒核弹，乱纪元一起发射。
- **核弹按波次打**：三体人对一个国家打完一波核包裹（6 秒内）后，35 秒内不再对它发射核包裹（导弹和小摩托照常），转去打别的国家；每打一波，对这个国家的怒气减 30。护盾冷却 30 秒，所以每一波到来时护盾都能转好。
- 纯 AI 测试中三体人胜率约 33%（3 个 AI）；国家越多它越难赢（5 个 AI 约 16%）。

## 快速局

开始界面勾选「⚡ 快速局」：午夜提前到第 4 分钟，产出加倍，末日升级、三体人的乱纪元等计时减半，大招冷却打七五折，护盾持续时间缩短到四成，一局约 5～6 分钟。可以和生存模式一起勾选，联机时由房主决定。

## 联机（测试版）

- 开始界面点 **🌐 创建房间**，把房间码或「复制邀请链接」发给朋友；朋友打开链接，或输入房间码点「加入」。
- 每人选一个国家（可以和别人重复，重复的国家会换颜色），房主设置 AI 数量、难度和速度后开始。最多 8 个国家（真人 + AI）。
- 房主的浏览器运行整个世界，其他人通过浏览器直连（WebRTC，借助 PeerJS 的公共服务器牵线），不需要自己的服务器。
- 联机时不能暂停或加速。有人掉线，由 AI 接管他的国家；房主退出，这局结束。
- 一局结束后点 **回到房间，再来一局**：连接保持，所有人回到房间后可以换国家、改名，新朋友也能加入，房主再点开始即可。
- 少数网络环境（部分公司网、移动网络）可能无法直连。

## 本地运行

纯 HTML + CSS + JavaScript，没有任何依赖。在本目录启动一个静态服务器即可：

```bash
python -m http.server 8765
```

然后浏览器打开 `http://localhost:8765`。Windows 下也可以直接双击 `start.bat`。

## 技术说明

- Canvas 2D 渲染，发光效果用叠加混合实现；音效和背景音乐用 WebAudio 实时合成，没有任何音频文件。
- 所有数值集中在 `js/config.js`，方便调整平衡。
- 代码按职责分文件（普通脚本，按 `index.html` 里的顺序加载，不需要打包）：
  - `js/sim/`：模拟。`core` 开局与工具，`step` 每步推进与生产，`strike` 核包裹/导弹/小摩托与命中，`defense` 空战/拦截/护盾/大招/重建，`boss` 三体人（智子、乱纪元、降维打击），`events` 全球事件，`end` 胜负判定
  - `js/ui/`：界面。`base` 面板与通用，`strike` 发射按钮/选目标/地图浮窗，`rank` 人口排行榜，`tips` 新手引导与局势提示，`end` 结算与人口走势图
  - `js/render/gl.js`、`glscene.js`：WebGL 画法（PixiJS 7，从 unpkg 动态加载）。`gl` 是基础设施（贴图合批层、线条层、尾迹网格、贴图和文字缓存），`glscene` 用它画整帧画面，内容和顺序与 Canvas 2D 画法一一对应，预渲染的缓存图两套画法共用。加载失败、设备不支持 WebGL 或运行中出错时自动退回 Canvas 2D；网址加 `?nogl` 可强制用 Canvas 2D
  - WebGL 画法独有的效果：**泛光**（尾迹、火球、火星等高亮层模糊后叠回画面）、**冲击波扭曲**（3 级以上核弹的冲击环扫过时折射下面的地图）、**着色器火球**（4、5 级核弹，火焰纹理实时计算，4 级带彩虹边）、高级核弹的火星 / 碎片 / 尘浪加量。自动画质降到一半以下时关闭泛光和扭曲
  - `js/render/`：绘制。`base` 地图与城市，`units` 飞行物与来袭准星，`labels` 国家标签，`boss` 降维打击与乱纪元
  - `js/icons.js` 种族徽章（SVG）
  - `tools/balance.html` 平衡测试页：在后台线程批量跑对局，输出时长、胜率、科技时间线（本地起服务器后打开 `/tools/balance.html`）
  - `ai.js` AI，`fx.js` 特效，`audio.js` 音效，`net.js` 联机，`main.js` 主循环与输入
